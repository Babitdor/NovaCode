# NovaCode v1.0.67

## Improved

- Council now has an advisor sidebar on the left and a dedicated conversation
  area on the right, with discussion controls and question suggestions.
- Cowork uses the same conversation layout, with workspace permissions, tasks,
  and activity accessible through tabs in the left sidebar.
- Mobile sidebars open as drawers with keyboard focus handling and Escape to
  close. Both pages use a compact header and a persistent chat composer.
- Added browser regression checks for streaming, follow-ups, approval, workspace
  grants and revocation, questions, cancellation, and mobile navigation.
