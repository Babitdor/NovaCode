# NovaCode v1.0.61

## Added

- `/share all` starts temporary shares for Artifacts, Council, Cowork, and
  Create, then provides one responsive dashboard with links to each page.
- Sharing pages individually refreshes the dashboard when the Artifacts share
  is active. The dashboard marks pages that are not currently shared.
- Dashboard links open outside the artifact preview sandbox so each shared app
  retains its normal browser behavior.
