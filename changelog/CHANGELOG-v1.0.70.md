# NovaCode v1.0.70

## Improved

- Cowork now matches Council's slate and sea-glass palette, editorial welcome typography, and refined conversation, question, permission, and activity panels.
- Each Cowork sidebar tab uses one keyboard-scrollable region, including folder controls, grants, tasks, and activity. Tabs, section headings, and workspace status remain fixed.
- Council and Cowork sidebars use slimmer scrollbars, stable scrollbar spacing, and contained scrolling. Long session identifiers no longer crowd out sidebar content.
- Refined mobile spacing and retained workspace permissions, chat, cancellation, and session controls.

## Validation

- Added browser coverage with 35 granted folders and 30 tasks on short desktop and phone screens, including keyboard scrolling and access to the final items.
- Existing Council/Cowork browser and Cowork server checks cover the shared layout and preserved behavior. No new runtime dependencies.
