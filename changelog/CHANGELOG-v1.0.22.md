# NovaCode v1.0.22

- Fixed ANSI theme color parsing that made inline code and file paths appear as solid gray blocks in resumed sessions.
- Added a contrast check for inline code and CSS color/alpha support.
- Cached replies now refresh their colors when the theme changes while preserving rendering performance.
- Added five themes to `/themes`: `nova-synthwave`, `nova-aurora`, `nova-ember`, `nova-abyss`, and the light `nova-paper` palette.
