01 · the workflow

Give it a task. Stay in the loop.

Nova reads project context, works across files, and runs commands through the terminal. You can steer it as it goes and inspect the result.

Memory you can inspect

Useful notes live in files you can open, search, edit, or remove.

02 · memory

A Markdown wiki, on your machine.

Nova keeps preferences and topic notes in readable Markdown. It can search the notes and open the source page, so you can see what it is using as context.

You stay the source of truth

Memory is ordinary text, not a hidden profile. Read it directly, correct it when a detail changes, or delete notes you no longer want Nova to use.

Find the wiki in ~/.nova/agents/<agent>/memories/.

Memory can provide context; it does not prove that a remembered claim is still true.

03 · control

Review plans. Set tool approvals.

Nova can investigate in plan mode before it changes code. Tool approvals follow a policy you can configure, with hard-coded denials still enforced.

Review before implementation

Use a plan to inspect the proposed approach and decide whether to proceed. Approved plans are saved with the project and in Nova's archive.

Set tool approval rules

Choose when Nova asks before using tools. Approval behavior is configurable, so review the policy that fits your workflow.

install

Install Nova and start in your repository.

Nova requires Python 3.11 or newer and uv. Install the command-line app, then run nova from your project. To work on Nova itself, use the source checkout instructions.

macOS and Linux · installed copy

uv tool install "novacode-cli @ git+https://github.com/Babitdor/NovaCode.git"

windows · from source

git clone https://github.com/Babitdor/NovaCode.git; cd NovaCode; uv sync

any platform · then run

nova

Nova is open source under the MIT license. Choose a hosted model provider or configure a local Ollama model.

± An installed copy is not a development checkout. If you want to change Nova, use the clone path and uv run nova, or your edits will not load.

questions

Before you install.

The practical details for getting started.

What does Nova do?

Nova is an open-source coding agent for the terminal. It can explore a repository, edit files, run commands, and help you understand the code. Read the documentation.

Where does Nova keep memory?

In Markdown files under ~/.nova/agents/<agent>/memories/. You can read and edit these files yourself. Memory is context, not verification.

Do I approve every action?

Tool approvals are configurable by operation. Plan mode lets you review an approach before implementation, and hard-coded denials cannot be disabled through the approval policy. See permission details.

Which models and operating systems are supported?

Nova supports hosted providers and local Ollama models. It requires Python 3.11 or newer and runs on macOS, Linux, and Windows. Some providers need their own account or API credentials.
