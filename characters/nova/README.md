# Nova companion

Generated with the built-in image tool using `assets/coin.png` for identity and
style. The source sheets have real alpha. Each is a 3 x 3 head-and-shoulders grid.

Directions prompt: coin-inspired chibi Nova with a short warm brown bob, brown
eyes, peach skin, gold earrings and navy zip hoodie with an orange crescent;
confident ink outlines and fine hatching. One repeated forward-facing body,
nine head directions from viewer-left to viewer-right and up to down, centered
with generous transparent margins. No hands, props, grid, labels or background.

Reactions prompt: match the directions sheet's front-facing character, body,
scale, position and palette exactly. Nine expressions: calm closed eyes, heart,
sparkles, surprised, starstruck, blush, sleepy, dizzy, delighted. Only the face
and small expression symbols change; preserve transparent margins.

Built with the page-mascot skill's shoulder-aligned atlas pipeline. Verification:
0.00 rendered pixels of movement on reaction, 94.2% shoulder overlap,
86.2% palette match, 0.5% shoulder-width change. Left/right directions inspected.
The generated PNGs are retained for rebuilding; the website uses the two WebPs
in `assets/mascots/` with native CSS background positioning and JavaScript.
